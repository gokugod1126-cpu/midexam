# 智慧路口交管小幫手（NUCLEO-G474RE 期中專題）

平凡路口因應不同時段車流量自動切換紅綠燈時序，並具備突發事故手動介入控制功能。

## 1. 情境故事：誰、在哪、遇到什麼麻煩
* **誰**：每天通勤的用路人與需處理突發路況的交通指揮人員。
* **在哪**：社區旁一個看似平凡、但上下班尖峰與夜間車流量落差極大的十字路口。
* **遇到什麼麻煩**：固定時序的紅綠燈無法消化尖峰車潮，且路口若發生車禍或突發狀況時，無法即時人工介入指揮，容易造成嚴重回堵與安全危機。

## 2. 替身對照：故事裡的模組 → 板上替身
* 一般車流 / 上下班 / 晚間休息模式（A、B、C 模式循環） → `STM32G474` 內部計時與狀態機自動循環
* `PC0` = `led_red` → 路口紅燈號誌[cite: 1]
* `PC1` = `led_yellow` → 路口黃燈號誌[cite: 1]
* `PC2` = `led_green` → 路口綠燈號誌[cite: 1]
* `PC3` = `int` → 緊急/手動模式切換按鍵（外部中斷 EXTI）[cite: 1]
* `PC4` = `mode` → 手動模式下紅綠燈切換按鍵（放開觸發 Toggle）[cite: 1]

## 3. 功能與驗收條件：動作、預期、實測結果
* **自動循環模式**：開機預設進入自動模式，依序執行「模式 A (綠5s/黃1s/紅5s) → 模式 B (綠5s/黃1s/紅3s) → 模式 C (綠3s/黃1s/紅5s)」並不斷循環 → **實測通過**。
* **中斷切換手動**：按下 PC3 (`int`) 後立即跳脫自動循環，進入手動模式 → **實測通過**。
* **手動按壓切換**：在手動模式下，每次按下並放開 PC4 (`mode`)，紅燈與綠燈即相互切換 → **實測通過**。
* **恢復自動模式**：再次按下 PC3 (`int`)，系統即無縫切換回原本的自動循環模式 → **實測通過**。

## 4. 用到的技術：第 3 ~ 7 週勾選表（同投影片）
* GPIO 輸出控制（Push-Pull 驅動 LED）[cite: 1]
* 外部中斷 (EXTI) 與防彈跳處理 (`HAL_GPIO_EXTI_Callback`)
* 狀態機架構 (State Machine) 與非阻塞式時間管理（`HAL_GetTick`）

## 5. 腳位表：用到的每支腳與用途
* `PC0` = `led_red`（紅燈輸出）[cite: 1]
* `PC1` = `led_yellow`（黃燈輸出）[cite: 1]
* `PC2` = `led_green`（綠燈輸出）[cite: 1]
* `PC3` = `int`（模式切換外部中斷，內部上拉）[cite: 1]
* `PC4` = `mode`（手動模式燈號切換輸入）[cite: 1]
* `PA2 / PA3` = `USART2` (ST-LINK VCP，系統除訊)

## 6. 建置與執行：開發環境、燒錄步驟、終端機設定、命令
* **開發環境**：STM32CubeIDE (v1.15+)
* **燒錄步驟**：透過 ST-LINK 連接 NUCLEO-G474RE 開發板，點擊 Run / Debug 進行編譯與燒錄。
* **終端機設定**：115200 8N1；命令列或按鍵對應：
  * 系統啟動即自動跑 A、B、C 模式。
  * 按下接在 `PC3` 的按鍵 → 切換為手動指揮模式[cite: 1]。
  * 在手動模式下，每次按下並放開接在 `PC4` 的按鍵 → 紅綠燈互換[cite: 1]。
  * 再次按下 `PC3` → 恢復自動循環[cite: 1]。

## 7. 程式結構：哪個檔做什麼、ISR 與主迴圈分工
* `main.c`：
  * **主迴圈 (`while(1)`)**：依據 `current_system_state` 決定執行 `Handle_Auto_Mode()` 或是 `Handle_Manual_Mode()`。
  * **ISR（中斷服務函式）**：`HAL_GPIO_EXTI_Callback()` 負責監聽 `PC3` 觸發，即時切換系統狀態（防彈跳 200ms）[cite: 1]。
  * **輔助邏輯**：`Interruptible_Delay()` 確保自動模式的延遲能隨時響應中斷打斷。

## 9. AI 使用說明：哪段請 AI、你怎麼查核
* **協作段落**：請 AI 協助設計「可被中斷打斷的非阻塞式延遲 (`Interruptible_Delay`)」以及「PC4 按下後放開才切換狀態（Toggle）的邊緣偵測邏輯」[cite: 1]。
* **查核方式**：透過實際燒錄至開發板上測試：觀察延遲中途按下中斷的反應速度是否靈敏，並確認 PC4 是否確實為「放開後」才改變燈號，逐一驗證邏輯無誤[cite: 1]。

## 10. 已限制制：哪些用替身、換真貨要改哪裡
* **目前限制**：使用板上外接的簡單三色 LED 模擬真實交通號誌燈。
* **換真貨改哪裡**：若要改接高功率的戶外實體紅綠燈（如 12V / 110V 燈具），需將 `PC0~PC2` 的 GPIO 訊號外接繼電器 (Relay) 或 MOSFET 驅動模組，並在程式中注意共地與隔離保護[cite: 1]。
